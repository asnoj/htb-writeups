# Concepts

- **Recon**: nmap `-sC -sV`, NSE scripts like `smb-vuln-*`
- **SMB**: SMBv1, MS08-067, MS17-010 (EternalBlue)
- **Outdated services**: version -> CVE -> exploit
- **IDOR**: accessing resources through an unprotected identifier
- **Cleartext protocols**: FTP/HTTP, credential sniffing
- **Linux capabilities**: `cap_setuid` -> root
- **Password reuse**
